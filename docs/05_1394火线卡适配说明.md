# 05 — IEEE-1394 火线卡适配（VIA / TI 廉价卡）

> 目的：在 Win11 上把便宜的 PCI/PCIe 1394a 卡跑起来，让 NJB3 走火线而不是 USB 1.1。
> 实测参考：75MB 文件 USB 1.1 约 2 分 25 秒（≈0.5 MB/s），1394 约 23 秒（≈3.3 MB/s）。

---

## 1. 结论先行

**不需要第三方"Win11 1394 驱动"。** Windows 自带的、已签名的 `1394ohci.sys` 已经覆盖这些卡。
真正要做的是：

1. 让系统把自带驱动正确绑定到卡上（脚本 `install_1394_host.ps1` 帮你做检测/重扫）；
2. 再装 **Creative 的 1394 设备端驱动**（`ctpd1394.inf` / `ctpdfwx.sys`），让 NJB3 作为 PDE 设备出现；
3. 用 CMS5 或 libnjb 经 1394 传歌。

---

## 2. 芯片与硬件 ID 对照

| 厂商 | 芯片 | 硬件 ID | 常见卡型 |
|---|---|---|---|
| VIA | VT6306/7/8 Fire II(M) | `PCI\VEN_1106&DEV_3044` | 老 PCI 卡 |
| VIA | **VT6315N** | `PCI\VEN_1106&DEV_3403` | **廉价 PCIe 4 口卡**，设备 ID 来自 VT6315N datasheet |
| TI | TSB12LV22 | `PCI\VEN_104C&DEV_8009` | 早期卡 |
| TI | TSB12LV23 | `PCI\VEN_104C&DEV_8019` | 早期卡 |
| TI | TSB12LV26 | `PCI\VEN_104C&DEV_8020` | Link 芯片 |
| TI | **TSB43AB22A** | `PCI\VEN_104C&DEV_8023` | **经典 PCI 卡（iOHCI-Lynx）** |
| TI | TSB43AB23 | `PCI\VEN_104C&DEV_8024` | 多口卡 |
| TI | TSB82AA2 | `PCI\VEN_104C&DEV_8025` | 1394b Link |
| TI | XIO2200A | `PCI\VEN_104C&DEV_8235` | PCIe 卡 |

> 两家的卡 class code 都是 `0C0010`（`PCI\CC_0C0010`），这是 Windows 能通用识别的关键。

---

## 3. 证据：系统自带 INF 原文

来自本机 `C:\Windows\INF\1394.inf`（UTF-16LE，Windows 10 19041 系列；Win11 同架构）：

```ini
[Version]
Signature="$Windows NT$"
Class=1394
Provider=%MSFT%
DriverVer = 06/21/2006,10.0.19041.1

[Generic.NTamd64]
%PCI\CC_0C0010.DeviceDesc%=Generic.Install,PCI\CC_0C0010

[Generic.Install.NT.Services]
AddService=1394ohci, 2, Generic.AddService

[Generic.AddService]
ServiceBinary = %12%\1394ohci.sys

[TI.NTamd64]
%PCI\VEN_104C&DEV_8009.DeviceDesc%=Generic.Install,PCI\VEN_104C&DEV_8009
%PCI\VEN_104C&DEV_8019.DeviceDesc%=Generic.Install,PCI\VEN_104C&DEV_8019
%PCI\VEN_104C&CC_0C0010.DeviceDesc%=Generic.Install,PCI\VEN_104C&CC_0C0010

[VIA.NTamd64]
%PCI\VEN_1106&DEV_3044.DeviceDesc%=Generic.Install,PCI\VEN_1106&DEV_3044
%PCI\VEN_1106&CC_0C0010.DeviceDesc%=Generic.Install,PCI\VEN_1106&CC_0C0010
```

VT6315N（3403）与 TSB43AB22A/23（8023/8024）虽未逐条列出，但都由 `CC_0C0010` 类 ID 命中。
系统驱动文件：`C:\Windows\System32\drivers\1394ohci.sys`（实测存在）。

**因此**：网上流传的"VIA/TI 1394 驱动 6.0"之类第三方包是 XP~Win8 时代的未签名驱动，
在 Win11 + HVCI 下可能被拦截，反而不如系统自带的稳定。不要优先用它们。

## 4. 操作步骤

### 4.1 只读检测

```powershell
cd G:\Drivers\jukebox3_win11\scripts
.\install_1394_host.ps1 -OnlyCheck
```

输出会列出 1394 控制器的 Status / FriendlyName / 硬件 ID，并标注是否被自带驱动覆盖。

### 4.2 安装

```powershell
# 管理员 PowerShell
.\install_1394_host.ps1
```

它会：
1. 列出卡片硬件 ID；
2. 对 `C:\Windows\INF\1394.inf` 执行 `pnputil /add-driver ... /install`（已存在时会提示，属正常）；
3. `pnputil /scan-devices` 触发重扫；
4. 调用 `install_win11_driver.ps1 -Mode IEEE1394` 安装 Creative 1394 设备端驱动；
5. 输出电源管理与插槽建议。

然后**关机插卡 → 开机 → 用 6-pin↔4-pin 火线连接 NJB3 → 打开机器**。
设备管理器应出现：

- IEEE 1394 主机控制器 → `VIA 1394 OHCI Compliant Host Controller` 或 `Texas Instruments 1394 OHCI Compliant Host Controller`
- IEEE 1394 设备 → `NOMAD Jukebox 3 1394`（ Creative 驱动装好后）

### 4.3 手动兜底

若卡仍是感叹号：设备管理器 → 右键卡 → 更新驱动 → 浏览计算机 →
"让我从计算机上的可用驱动程序列表中选取" → 选 `1394 OHCI Compliant Host Controller`
（若系统提供 `(Legacy)` 版本且设备识别异常，可试 Legacy 后重启）。

若 NJB3 仍是未知设备：右键 → 更新驱动 → 从磁盘安装 →
`C:\Program Files\NJB3-Win11\creative_pde_1394\ctpd1394.inf` → 选 `NOMAD Jukebox 3 1394`。

## 5. 排错清单

| 现象 | 原因 / 处理 |
|---|---|
| 设备管理器看不到卡 | BIOS 中 PCIe/PCI 槽被禁用；换槽；检查卡片供电；"显示隐藏的设备" |
| 卡有感叹号 Code 10/28/31 | 驱动被第三方包污染：卸载设备+删除驱动 → 重启 → 只让系统自带驱动接管 |
| 卡正常但 NJB3 不出现 | 线缆问题（6-4pin 一定要是数据线，不是只供电）；NJB3 未开机；先用 USB 验证机器本身正常 |
| 1394 Net Adapter 没出现 | 不影响 NJB3：PDE 是 1394 设备协议，不依赖 IPC/网络适配器 |
| 传输中途断开 | 关闭 1394 控制器的节能；VT6315N 卡接大功率设备时接 4-pin 辅助供电；换 TI 卡（时序更稳） |
| 找不到 Legacy 驱动 | Win11 新版 INF 通常不含该项，属正常；Creative PDE 不需要 Legacy 也能工作 |

## 6. 性能与局限

- 1394a 理论 400 Mbps，NJB3 实测约 **3.3 MB/s**，仍远快于 USB 1.1 的约 0.5 MB/s。
- 瓶颈还包括 NJB3 内部硬盘与 PDE 协议开销，达不到 400 Mbps 理论值。
- 机器仍不是 U 盘：经火线传歌依然要写内部数据库，必须通过 CMS5 或 libnjb，**不能**直接往盘里拷文件。
- 若你的主板没有空槽，PCIe x1 转接卡或 Thunderbolt→FireWire 主动适配器是替代方案；
  被动 USB↔FireWire 线**不能**用于数据传输。
