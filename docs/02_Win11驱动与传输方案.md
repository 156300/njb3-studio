# 目标 1：Win11 稳定驱动 + 传输软件（ID3 / 播放列表 / 设置）

## 判决：可实现。两条路线，二选一（互斥）

| | 路线 A：原厂 WMDM 栈 | 路线 B：开源 libnjb 栈 |
|---|---|---|
| 驱动 | Creative `ctpdusb.inf`（手动安装） | Zadig 装 WinUSB/libusbK |
| 软件 | CMS5 + CMS5-NJB2 插件 | libnjb 工具 + `njb3_transfer.py` |
| Win11 实测 | 社区已验证可用（NJB2/3/Zen） | libnjb 官方支持 Windows |
| ID3/元数据 | CMS5 界面编辑 | `njb-tagtr` / 上传时写元数据 |
| 播放列表/m3u | CMS5 界面 | `njb-pl` / 本工具 m3u 映射 |
| 优点 | 最接近原厂体验、设置项最全 | 现代、可脚本化、批量、免老安装器 |
| 缺点 | 老安装器在 Win11 常解压失败 | 需自行装 libnjb；设置项少于 CMS5 |

**建议**：先用路线 A 让设备"活"起来并验证连接；若要批量/自动化传歌与 m3u，再切路线 B。切换时需在设备管理器里更换驱动绑定，**同一时刻只能用一套**。

## 路线 A：原厂驱动（关键在"手动安装"）

### 为什么会失败
创新原版 `JB3_PCFW`/`JukeboxDrivers` 安装器在 Win7/10/11 上常无法完整解压 `JBSeriesDrv` 文件夹，导致报"找不到指定文件"。但**驱动文件本身是完好的**——社区共识做法是绕过安装器，手动指定 INF。

### 步骤

1. **准备驱动文件**（不要改原文件夹）：本方案已把驱动留在原处。使用目录：
   `G:\Drivers\jukebox3\win10\Creative_USB_x86_x64\Jukebox 3 Drivers\`
   关键文件：`ctpdusb.inf`、`ctpdusbx.sys`（x64）、`ctpdusb.cat`/`ctpdusbx.cat`、`ctpde.dll`、`CPdeSrvU.exe`、`CPmsManU.dll`、`CTPmsMan.dll`、`ctjb2sp.dll` 等（INF 的 `SourceDisksFiles` 段列出全部，缺一不可）。

2. **管理员 PowerShell 预置驱动库**（可选但推荐）：
   ```powershell
   .\scripts\install_win11_driver.ps1 -SourceDir "G:\Drivers\jukebox3\win10\Creative_USB_x86_x64\Jukebox 3 Drivers"
   ```
   脚本会把文件复制到稳定目录、`pnputil /add-driver` 注册到驱动库，并检查签名状态。

3. **连接设备并手动绑定驱动**：
   - 设备管理器 → 找到带感叹号的 "NOMAD Jukebox 3"（或未知 USB 设备）→ 右键"更新驱动程序"
   - → "浏览我的电脑以查找驱动程序" → "让我从计算机上的可用驱动程序列表中选取"
   - → "从磁盘安装" → 浏览指向 `ctpdusb.inf` → 选中列表里的 **"NOMAD Jukebox 3"** → 下一步。

4. **驱动签名**：这些驱动是 2006 年的 WHQL 签名（`DriverVer=01/19/2006`）。多数 Win11 能直接接受；若提示签名问题，用**临时**方式（重启进高级启动 → 启动设置 → 禁用驱动程序强制签名），装完重启即恢复，不必长期开测试模式。注意：若开启了"内存完整性/HVCI"，需先在 `Windows 安全中心 → 设备安全性 → 核心隔离` 关闭它，否则老驱动可能无法加载。

5. **安装管理软件**（顺序不可颠倒）：
   - 先装主程序：`creativemediasource52502/CMS5_PCAPP_LB_5_25_02.exe`
     （或 win10 目录里更新的 `CMS5_PCAPP_LB_5_10_38.exe`，两者任选其一；不要同时装）
   - 再装 NJB2/NJB3 插件：`CMS5_NJB2_PCAPP_LB_5_00_22.exe`（文件名含 NJB2，但 NJB3 也用它）
   - MTP 机型才需要 `CMS5_MTP_PCAPP_LB_5_00_36.exe`；**NJB3 属于非 MTP 的 PDE 机型，不要装 MTP 插件**。

6. **兼容模式**：若安装器仍无法运行，右键 exe → 属性 → 兼容性 → 以 Windows XP SP3 / Windows 7 兼容模式 + 管理员运行；或用 7-Zip 直接解压 exe 后运行里面的 `Setup.exe`。

### CMS5 里做什么
- 传歌：媒体源 → 传输到播放器（会同时写入 ID3/曲库元数据，机器才能按 artist/album 区分）
- 编辑 ID3：选中曲目 → 编辑音频曲目信息
- 播放列表：创建/编辑播放列表 → 同步到设备
- 机器设置：Jukebox 设置（EQ、语言、电源、开机图片等）——这部分 CMS5 最全，libnjb 只能覆盖部分（如 `njb-setpbm` 播放模式）

## 路线 B：libnjb 开源栈（批量 / m3u / 自动化）

### 安装
1. **装通用 USB 驱动**：下载 Zadig（https://zadig.akeo.ie ）→ 连接 NJB3 → Options→List All Devices → 选 "NOMAD Jukebox 3 (041e:4101)" → 目标驱动选 **WinUSB**（若工具不认再试 libusbK / libusb-win32）→ Install。
   > 这会替换掉路线 A 的 Creative 驱动；两套互斥。想换回去就在设备管理器里重新指向 `ctpdusb.inf`。
   >
   > 注意：**libusb-win32 属于 libusb 0.1 体系**（API 为 `usb_*`，自带已签名的 `libusb0.sys`），与本项目内置的 **libusb 1.0.30**（WinUSB 后端、API 为 `libusb_*`）不是同一个库。2024-02-23 起它的开发迁至 https://github.com/mcuee/libusb-win32 。本项目走自签 CAT + WinUSB 路线，不依赖 libusb-win32；这里仅作为 Zadig 可选目标驱动列出。
2. **装 libnjb**：从 SourceForge `libnjb` 项目获取 Windows 构建（或使用 MSYS2/MinGW 编译 2.2.7 + libusb）。确认 `njb-tracks.exe` 等工具在 PATH 中。
3. **验证**：`njb-handshake` 应返回设备信息；`njb-tracks` 列出曲库。

### 用 njb3_transfer.py（本方案提供）

```powershell
# 1. 自检：探测 libnjb 工具 + 内置 ID3 解析器自测（不需要设备）
python scripts\njb3_transfer.py doctor

# 2. 列出设备曲库
python scripts\njb3_transfer.py list

# 3. 批量上传一个文件夹（自动读取 MP3 的 ID3 → 写入设备元数据）
python scripts\njb3_transfer.py upload --src "D:\music\album1" --playlist "新专辑"

# 4. 把 m3u 导入为设备播放列表（m3u 里的路径指向本地 mp3）
python scripts\njb3_transfer.py m3u-import --file "config\example_playlists\roadtrip.m3u" --upload-missing

# 5. 让设备按文件夹结构建立播放列表（每个子文件夹=一个播放列表）
python scripts\njb3_transfer.py folder-playlists --root "D:\music" --depth 1

# 6. 修改曲目元数据/ID3
python scripts\njb3_transfer.py tag --track 42 --title "新标题" --artist "歌手" --genre "Rock"

# 7. 设备设置：播放模式
python scripts\njb3_transfer.py settings --pbm shuffle-repeat

# 所有写操作先加 --dry-run 预览，确认后再去掉执行
```

工具细节见 `scripts/njb3_transfer.py` 顶部帮助。它内置纯 Python 的 ID3v1/ID3v2 解析（无第三方依赖），能生成正确的元数据供 `njb-sendtr` 写入。

### 关于 ID3 与"机器区分"
机器靠**数据库里的元数据字段**区分/排序曲目，不直接读文件 ID3。因此正确流程是：上传时从文件 ID3 解析出 title/artist/album/genre → 作为 `njb-sendtr` 的元数据参数写入设备数据库。`njb3_transfer.py upload` 已封装这一过程；若你的 MP3 没有 ID3，可先用 `--title/--artist` 手工指定，或先用工具内的 `id3-print` 检查标签。

### 播放列表与 m3u 的现实
- **可行**：通过 PDE API 在设备数据库里建播放列表（`njb-pl` / 本工具 `m3u-import`、`folder-playlists`）。
- **不可行**：把 `.m3u` 当普通文件拷到盘里让机器读取——机器不会扫描数据文件区的 m3u 来生成播放列表。必须由主机软件写入数据库。

## 验证清单（实机自测）
1. `njb-handshake` / 设备管理器无感叹号 → 驱动 OK
2. 上传 1 首歌 → 机器上 Music Library 能看到、能播放 → 元数据写入 OK
3. 编辑 ID3 → 按 artist/album 排序正确 → 索引 OK
4. 建播放列表 → 机器上 Playlists 可见 → 播放列表 OK
5. 传输 100 首 → 无掉线/无卡死 → 稳定性 OK（先小批量再大量）
