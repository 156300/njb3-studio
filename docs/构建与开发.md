# 构建与开发

## 1. 环境

- Windows 10/11，64 位
- Python 3.13（需包含 tkinter）
- 依赖（见 `src/scripts/requirements.txt`）：`pyusb`、`libusb-package`、`pillow`、`pywin32`、`pyinstaller`

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r src/scripts/requirements.txt
```

## 2. 目录约束

源码按如下相对结构放置，程序依赖它来定位业务模块与 DLL：

```
src/
├── ui_next/     njb3_studio.py, njb3_theme.py, njb3_dock.py, njb3_studio.spec
├── scripts/     njb3_gui.py, njb3_pde.py, ...（业务模块）
└── runtime/     libusb-1.0.dll
```

`njb3_studio.py` 会把 `src/scripts` 加入 `sys.path`，`njb3_pde.py` 会优先从程序目录或 `src/runtime`
加载 `libusb-1.0.dll`。**不要把这些目录拆散。**

## 3. 直接运行

```powershell
python src/ui_next/njb3_studio.py
```

首次连接某台 NJB3 会完整读取曲库（约 1 分钟）。调试时可用
`tools/diagnostics/diag_transfer_timeline.py` 观察各阶段耗时。

## 4. 打包绿色单文件

```powershell
python -m PyInstaller src/ui_next/njb3_studio.spec --distpath dist --workpath build -y
```

产物 `dist/njb3_studio.exe` 约 15MB，已内置 Python 运行时、tkinter 与 libusb DLL。
用户无需安装任何组件，只需一次性安装 WinUSB 驱动（见 [驱动安装与排错.md](驱动安装与排错.md)）。

注意：`spec` 中 `HERE` 为 `src/ui_next`，`ROOT` 为 `src`，DLL 从 `src/runtime` 取。
若移动 `spec` 文件，需同步调整这些路径。

## 5. 测试

```powershell
# 逐个运行（推荐，输出清晰）
for ($f in Get-ChildItem tests\test_*.py) { python $f.FullName }

# 或用 pytest
python -m pytest tests
```

当前 19 套测试，约 500 项断言，全部为**离线测试**：不连接设备、不依赖个人路径。
其中 `test_v46_library_cache.py` 覆盖缓存读写、序号匹配、代理分支与强制刷新标志。

真机诊断脚本位于 `tools/diagnostics/`，**不要**放进自动化测试，也不要用管道截断其输出。

## 6. 常见开发坑

| 现象 | 原因 / 处理 |
|---|---|
| 新版界面按钮点不动或操作了错误的树 | 菜单命令应绑定事件来源树，见 [ARCHITECTURE.md](ARCHITECTURE.md) 第 4 节 |
| 曲库只读到 208 首 | 结束标志判断错误；应看批尾零长度帧后的 `read_again`，不是 word4 |
| 播放到最后乱跳 | 不要加高频轮询或提前量；回到单一触发，见 [AI_DEVELOPMENT_JOURNEY.md](AI_DEVELOPMENT_JOURNEY.md) 第 4 节 |
| 设备卡死 | 诊断脚本被强杀，未执行 STOP/clear/recover/close；用 `try/finally` 并禁止管道截断 |
| 连接慢（约 1 分钟） | 首次读扩展曲库正常；确认缓存文件未被删除，或点手动刷新后重试 |
