# 使用说明

## 1. 启动

1. 解压绿色包到任意目录（建议路径中不要有中文和空格以外的特殊字符）。
2. 双击 `启动 NJB3 Studio.bat`。
3. 首次使用先以管理员身份运行 `安装 WinUSB 驱动.bat`，完成后重新插拔设备。
4. 连接 NJB3，软件自动读取设备信息、曲库与播放清单。

启动时默认显示**控制工作台**，可随时用顶栏三个按钮切换。

---

## 2. 三个工作台

### 传输工作台

- 左侧：本机资源管理器，浏览电脑里的 MP3，支持双击展开、表头排序。
- 中间：待传输列表，可拖拽排序、删除条目。
- 右侧：机器内歌曲，支持搜索、排序、选中删除/改名，可拖入播控队列或播放清单。
- 底部：目标播放清单选择、传完后的处理（写入清单/刷新）、传输进度弹窗。

传输时软件会先向设备发送停止播放指令，避免边播边写导致冲突。

### 播控工作台

- 左侧：播放清单列表与「清单内的歌曲」，支持专辑/流派列与排序。
- 中间：设备当前播放队列，可拖拽排序后写回设备。
- 右侧：播放控制——总开关、播放模式、音量、上一曲/下一曲、当前曲目与进度。

**播控模式**开启后，软件接管播放推进。强烈建议把 NJB3 本机设为**单次播放模式**，
否则设备连播与软件播控会互相冲突。确认弹窗里也有同样提示。

### 控制工作台

设备状态、播放控制、驱动安装、数据刷新、外观主题与日志六个模块，
每个都可拖动、贴边、折叠、调整大小（布局会保存）。日志栏上拖有上限，不会挤压其他模块。

---

## 3. 曲库与播放清单

- 曲库表：序号 / 标题 / 艺人 / 专辑 / 时长 / 分类文件夹 / 流派等列，点击列头可正反排序。
- 单元格可暂存修改（黄底红字），点底部同步按钮一次性写入设备。时长列不可编辑。
- 搜索框用于快速定位曲目；同类控件在多个工作台各有一份，操作只作用于当前所在表格。
- 播放清单支持拖入歌曲、拖动排序、复制一份再修改（copy-on-write）、保存/删除。
- 删除曲目时会同步清理它在所有播放清单中的残留成员，避免设备 rebuilding library。

---

## 4. 曲库缓存与刷新速度

首次连接某台机器要完整读取曲库（4827 首约 57 秒），之后按设备序号使用本地缓存，
连接只需约 3 秒。缓存只保存设备固件查询很慢的 `filename` / `folder` 两个字段，
标题、艺人、时长等始终取设备实时值，所以设备上的改动不会被缓存覆盖。

设备曲目发生增删后，点控制工作台的：

> **刷新完整曲库和播放清单(速度慢)**

强制完整重读并更新该机器的缓存。平时传输完成后的自动刷新走快读，不需要点这个按钮。

缓存文件 `njb3_library_cache.json` 会生成在程序目录，删除它会让下次连接重新完整读取。

## 5. 常见问题

| 问题 | 处理 |
|---|---|
| 连接失败 / libusb 打不开设备 | 确认已装 WinUSB 驱动且没有旧版 NJB3 工具占用设备；见 [驱动安装与排错.md](驱动安装与排错.md) |
| 曲库只有 208 首 | 属于旧版 bug，请使用 0.1.1-261123 或更新版本 |
| 连接到「播放清单」卡住 | 空清单读取超时已做兜底；若仍卡住请更新版本 |
| 播放到末尾滞后或乱跳 | 使用 v44 及以上；并确认设备设为单次播放模式 |
| 界面文字显示不全 | 检查系统缩放比例（建议 100%~125%）；主题可在控制工作台切换 |
| 提示 rebuilding library | 先关软件，重新连接；不要强行断电 |

---

## 6. 安全提示

- 传输和删改操作会写入设备内部数据库，操作前请自行备份重要歌曲。
- 不要同时运行两个 NJB3 工具窗口，它们会争抢 USB 接口。
- 本软件与 Creative 公司无关，仅用于自有设备的互操作性维护。
